<objective>
Ratify and record how ROADMAP Phase 1 success criterion 2's second conjunct is discharged — as an accepted override naming the sweep's rule-naming detector, or as a tracked deferral to Phase 3 — so the phase's verification can reach a verdict that a human actually stood behind.

Purpose: the verification report calls this shape exactly right — "a deliberate deviation where an alternative implementation satisfies the intent but not the literal wording. An accepted override would close it; so would waiting for Phase 3." Both routes require an act this agent cannot perform on the user's behalf: the overrides mechanism's `accepted_by` field is a named human, and the alternative is a decision to carry an open gap across two phases. So this plan stops, asks, and then writes down what was decided, where every later reader will find it.

**MVP user story (inherited from 01-01, deliberately not re-derived):** **As a** course student maintaining one public coursework repository, **I want to** open a single committed workspace file that shows the repository root, the shared-library tree and every homework as top-level roots, and to build any homework from the repository root with one command, **so that** every homework stays buildable, demonstrable and self-explanatory long after it was submitted. This gap-closure plan adds no user-facing capability; it makes the repository's own record of what Phase 1 delivered honest. The ROADMAP `**Goal:**` line is not in user-story form, so no story is invented — 01-01's derived story stands.

The discharge recorded by this plan is a mechanism substitution (a rule-naming detector standing in for a build failure), not a change to the project's identity model, so no promote-or-add-alongside decision is raised. <corrections_that_override_sources>
- **This plan is deliberately not autonomous.** The overrides mechanism requires a named human in its `accepted_by` field and an acceptance timestamp; the alternative routes the same gap to Phase 3, which carries an open gap across two phases. Neither is a decision an agent may take, so a `checkpoint:decision` carrying `gate="blocking-human"` precedes the recording. That gate is the one gate never auto-approved in any mode — auto-advance, an auto-chain run and a yolo run all stop at it, which is the point: an unattended run must not manufacture an acceptance.
- **Append to the roadmap; never rewrite it.** The original criterion 2 sentence stays byte-identical. 01-CONTEXT D-24 established the principle for the research files — they "deliberately keep contradictions visible, and editing them retroactively erases what was established" — and it applies with more force to the contract the phase was verified against. The discharge is a dated note beside the criterion.
- **`status`, `score` and the `gaps:` rows in the verification record are the verifier's.** Add the override block and its count; do not hand-write a passing verdict. Verification is re-run after this plan and recomputes all of them; a hand-written `passed` would be a claim no verification produced.
- **The override's `must_have` text must quote the criterion's own words.** The overrides mechanism matches by token overlap in either direction at an 80 % threshold, so an entry phrased as a paraphrase of the intent rather than in the criterion's vocabulary can fail to bind and leave the gap open while appearing recorded. Quote the failing clause's own nouns: the depth, one level deeper, the build, the depth rule being load-bearing.
- **Resolve PlatformIO explicitly.** This machine's Core is not on the interactive PATH, and a command whose first word is a `VAR=value` assignment is refused by the worktree isolation guard. Resolve the binary inside a quoted expansion in command position. 01-01 and 01-05 both recorded this.
- **The summary is a new, unignored file under a tracked directory** and is written once, after the last reading it could invalidate, then committed — the discipline 01-05 established.
- **Do not touch `.gitignore`, `tools/`, `shared/` or `homeworks/` in this plan.** Gap 2 and the depth measurement are plan 01-06's; this plan records a decision and re-runs gates. Re-editing an earlier plan's artifact would falsify the record of what shipped.
